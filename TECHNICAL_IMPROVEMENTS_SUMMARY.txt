IMPACTO:

  • UX: Doctor digita medicamento a cada receita

  • Performance: Sem cache, cada busca é lenta

  - Templates: 7 dias

  - POST WhatsApp: 100/hora
  Impacto: Protege infraestrutura

  - CPF, RG: AES-256 (Fernet)
  - Senhas: bcrypt (existing)
  - Tokens: JWT (existing)
  Impacto: LGPD compliance

AUDITORIA:

  - Rastreabilidade completa
  - IP + user agent + timestamp
  Impacto: Portaria 344 ANVISA

VALIDAÇÕES:
  - CPF válido (Módulo 11)
  - CRM válido (formato SP/RJ/etc)
  - Receita: data não futura
  - Medicação: dosagem vs medicamento
  Impacto: Dados confiáveis

================================================================================

  Mitigation: Índices + cache Redis + pagination
  Impact: Baixo (índices fazem diferença)

  Impact: Médio (redesign sync se necessário)

  Mitigation: Fallback email + retry logic + logs
  Impact: Baixo (graceful degradation)

RISCO 4: Regressão em funcionalidade existente
  Mitigation: Testes antes de qualquer alter table
  Impact: Médio (rollback plan documentado)

RISCO 5: Performance timeline com 1000+ eventos
  Mitigation: Pagination + índices + cache
  Impact: Baixo (já testado com índices)
