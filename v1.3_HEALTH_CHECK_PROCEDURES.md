## 📊 HEALTH CHECK OVERVIEW

**Purpose:** Verify system health and performance post-deployment  
**Frequency:** Daily for first 30 days, then weekly  
**Owner:** On-Call Engineer / Release Manager  
**Duration:** 15-20 minutes per check  
**Success Criteria:** All green, all thresholds met

## 1. AUTOMATED HEALTH CHECKS

### 1.1 Backend Health Endpoint

```bash
# Endpoint Details
Method: GET
URL: https://ortho-backend.onrender.com/health
Timeout: 5 seconds
Expected Status: 200 OK

# Execute check
PowerShell:
$response = Invoke-WebRequest https://ortho-backend.onrender.com/health `
    -TimeoutSec 5 `
    -ErrorAction SilentlyContinue

if ($response.StatusCode -eq 200) {
    Write-Host "✓ Backend health check PASSED"
    $content = $response.Content | ConvertFrom-Json
    Write-Host "  Status: $($content.status)"
    Write-Host "  Version: $($content.version)"
    Write-Host "  Database: $($content.database)"
} else {
    Write-Host "✗ Backend health check FAILED: $($response.StatusCode)"
    # ESCALATE IMMEDIATELY - See escalation procedure
}

# Expected Response Body:
{
  "status": "ok",
  "version": "1.3.0",
  "database": "connected",
  "timestamp": "2026-06-07T15:30:00Z",
  "uptime_seconds": 3600
}
```

**Pass Criteria:**
- [ ] Status code: 200 OK
- [ ] Status field: "ok"
- [ ] Database: "connected"
- [ ] Response time: < 1 second

### 1.3 API Connectivity Test

```bash
# Critical API Endpoints
Endpoints to test:
1. GET /api/health → System health
2. GET /api/clinics → Data availability
3. GET /api/patients → Database connectivity
4. GET /api/appointments → Recent data

# Execute tests
PowerShell:
$baseUrl = "https://ortho-backend.onrender.com"
$endpoints = @("/api/health", "/api/clinics", "/api/patients", "/api/appointments")

$results = @()
foreach ($endpoint in $endpoints) {
    try {
        $response = Invoke-WebRequest "$baseUrl$endpoint" `
            -TimeoutSec 5 `
            -ErrorAction Stop
        $results += [PSCustomObject]@{
            Endpoint = $endpoint
            Status = "OK"
            Code = $response.StatusCode
            Time = "$(($response.Headers['Date']))"
        }
    } catch {
        $results += [PSCustomObject]@{
            Endpoint = $endpoint
            Status = "FAILED"
            Code = $_.Exception.Response.StatusCode
            Error = $_.Exception.Message
        }
    }
}

$results | Format-Table -AutoSize
```

**Pass Criteria:**
- [ ] All endpoints return 200 OK
- [ ] Response times < 500ms each
- [ ] No timeout errors
- [ ] No 5xx server errors

## 5. SECURITY & COMPLIANCE CHECK

### 5.1 HTTPS/TLS Verification

```bash
# Verify all traffic is encrypted

PowerShell:
# Check HTTPS redirect
$httpResponse = Invoke-WebRequest http://ortho-frontend.onrender.com `
    -FollowRelationships `
    -MaximumRedirection 5 `
    -ErrorAction SilentlyContinue

if ($httpResponse.BaseResponse.RequestMessage.RequestUri.Scheme -eq "https") {
    Write-Host "✓ HTTP automatically redirects to HTTPS"
} else {
    Write-Host "⚠ HTTP not redirecting to HTTPS"
}

# Check SSL/TLS Certificate
PowerShell:
$hostname = "ortho-frontend.onrender.com"
[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

try {
    $request = [Net.HttpWebRequest]::Create("https://$hostname")
    $request.GetResponse() | Out-Null
    $cert = $request.ServicePoint.Certificate
    
    Write-Host "✓ SSL/TLS Certificate Valid"
    Write-Host "  Subject: $($cert.Subject)"
    Write-Host "  Issuer: $($cert.Issuer)"
    Write-Host "  Expiry: $([datetime]::ParseExact($cert.GetExpirationDateString(), 'M/d/yyyy h:mm:ss tt', $null))"
} catch {
    Write-Host "✗ SSL/TLS Error: $($_.Exception.Message)"
}
```

**Pass Criteria:**
- [ ] All traffic forced to HTTPS
- [ ] Valid SSL/TLS certificate
- [ ] Certificate not expired
- [ ] Certificate expires > 30 days away

## 8. ESCALATION PROCEDURES

### 8.1 When to Escalate

| Severity | Condition | Action | Escalate To |
|----------|-----------|--------|-------------|
| P0 (Critical) | Service down, Data loss | Immediate | Team Lead + CTO |
| P0 (Critical) | Error rate > 5% | Immediate | Team Lead + CTO |
| P1 (High) | Error rate 0.5-5% | 15 min | Team Lead |
| P1 (High) | Performance degraded | 30 min | On-Call Engineer |
| P2 (Medium) | Minor feature broken | 1 hour | Team Lead |
| P3 (Low) | Cosmetic issue | Next day | Dev Team |

### 8.2 Escalation Process

```bash
# Step 1: Identify severity (5 minutes)
# - Determine P0/P1/P2/P3
# - Assess impact: users affected? data at risk?
# - Document findings

# Step 2: Initial actions
# - If P0: Declare incident, notify team
# - If P1: Create urgent ticket, notify team
# - If P2+: Create regular ticket, log for triage

# Step 3: Escalation path
P0: On-Call → Team Lead → CTO → VP Engineering
P1: On-Call → Team Lead → Senior Engineer
P2: Ticket → Team Lead → Next sprint
P3: Ticket → Backlog

# Step 4: Communication
# - Notify all stakeholders immediately
# - Update status page
# - Post in Slack #incidents channel
# - Set expected resolution time

# Step 5: Resolution tracking
# - Owner assigned
# - Root cause identified
# - Fix deployed
# - Verification completed
# - Post-incident review scheduled
```

## 11. TROUBLESHOOTING QUICK REFERENCE

### Problem: Backend Returns 502 Bad Gateway

```bash
Diagnosis:
1. Check Render dashboard → Backend service
   - Is service running? (Status should be "Live")
   - Has it restarted recently? (Check Events tab)

2. Check backend logs
   - Render → Backend → Logs
   - Look for "ERROR" or "CRITICAL"
   - What's the actual error?

3. Check database connection
   - Can backend connect to database?
   - Database status in Render Dashboard
   - Check DATABASE_URL environment variable

Resolution:
- If service down: Manual deploy or check logs for startup error
- If database down: Contact Render support
- If logs show error: Fix code and redeploy
- If 502 persists > 5 min: Consider rollback
```

### Problem: Frontend Loads Blank Page

```bash
Diagnosis:
1. Check browser console (F12 → Console)
   - Are there JavaScript errors?
   - Are there network errors (red entries)?

2. Check network tab
   - Are requests to backend succeeding?
   - Are all assets loading (JS, CSS, images)?

3. Check Frontend service in Render
   - Is it deployed and "Live"?
   - Check deploy logs for build errors
   - Check startup logs

Resolution:
- Clear browser cache (Ctrl+Shift+Delete)
- Hard refresh (Ctrl+Shift+R)
- Check NEXT_PUBLIC_API_URL environment variable
- If still broken: Check frontend logs, redeploy
```

### Problem: High Error Rate (> 0.5%)

```bash
Diagnosis:
1. Check what errors:
   - 5xx errors (server fault)
   - 4xx errors (client/request fault)
   - Timeout errors

2. Check error logs for pattern
   - All from one endpoint?
   - Random across all endpoints?
   - Started at specific time?

3. Check system resources
   - Is backend CPU/memory maxed out?
   - Is database slow?
   - Is there unusual traffic?

Resolution:
- If resource issue: Scale service
- If specific endpoint: Fix the code
- If database slow: Optimize queries
- If DDoS suspected: Contact Render support
- If can't fix quickly: Consider rollback
```

### Problem: Slow Response Times (> 1 second)

```bash
Diagnosis:
1. Check backend performance
   - Are API calls slow?
   - Are database queries slow?
   - Check /metrics endpoint for details

2. Check frontend performance
   - Use Lighthouse audit
   - Check network waterfall in DevTools
   - Identify slow resources

3. Check system load
   - Backend CPU usage
   - Database CPU/connections
   - Network latency

Resolution:
- Optimize slow queries (database)
- Optimize slow endpoints (backend)
- Optimize asset delivery (frontend)
- Scale if consistent load
- Cache results if possible
```
