3. ClickSign: Popup assinatura digital (certificado A1/A3)
4. ClickSign: Webhook notifica backend
5. Backend: Download PDF assinado, salva no banco
6. Medico: Recebe confirmacao, download, compartilha
7. Paciente: Recebe link WhatsApp
8. Farmacia/Publico: Valida receita via QR code

COMO USAR
==========

1. Copiar todos os 16 arquivos para seus diretorios
2. pip install reportlab qrcode Pillow requests
3. export CLICKSIGN_API_KEY="seu_token"
4. Criar tabelas: python -c "from database import Base, engine; from models.prescription import *; Base.metadata.create_all(bind=engine)"
5. Adicionar em main.py:
   from routers.prescriptions import router as prescriptions_router
   app.include_router(prescriptions_router)
6. Testar: pytest test_prescriptions.py -v
7. Deploy!
