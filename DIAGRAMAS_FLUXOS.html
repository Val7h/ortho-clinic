FLUXO 2: Assinatura Digital (ClickSign - CFM 2.299/21)

FRONTEND (Médico)

Etapa 1: Validação

  • Clique "Assinar Receita" (< 0.1s)
  • Valida dados (< 0.2s)

Etapa 2: Assinatura

  • Abre modal assinatura (< 0.3s)
  • Popup ClickSign para assinar (~30-40s)

Etapa 3: Confirmação

  • Poll status a cada 5s
  • Sucesso: Baixa PDF (< 1s)
  • Compartilha via WhatsApp (< 2s)
BACKEND (FastAPI)

POST /prescriptions/{id}/sign

  • Validação de dados (< 0.1s)
  • Gera PDF com QR Code (< 1s)

Upload ClickSign

  • Envia PDF para ClickSign (< 2s)
  • Obtém sign_url de retorno
  • Armazena doc_id no BD

Monitoramento

  • GET /prescriptions/{id}/signature-status
  • Webhook ClickSign → Salva PDF assinado
  • Envia para WhatsApp API
CLICKSIGN (API ICP-BR)

Processos

  • Recebe PDF (< 1s)
  • Gera sign_url assinatura
  • Médico assina no portal ClickSign (~30s)

Validação e Webhook

  • Valida assinatura (ICP-Brasil)
  • Faz POST em webhook OrthoClinic
  • Disponibiliza PDF assinado

⏱️ TIMELINE COMPLETA

Etapa Tempo Descrição
1. Clique 0s Médico clica "Assinar"
2. Geração PDF 1-2s Backend gera PDF com QR Code
3. Upload ClickSign 2-3s API ClickSign pronta para assinatura
4. Assinatura Médico 30-40s Médico assina no portal ClickSign
5. Webhook & BD 31-42s Documento salvo e disponível
Melhor caso: ~35s | Pior caso: ~60s

🔐 Conformidade CFM 2.299/21

  • Assinatura com certificado ICP-Brasil (ClickSign)
  • QR Code para validação de autenticidade
  • Proof de assinatura armazenado em BD
  • Timestamp de assinatura certificado
  • PDF com hash digital criptografado

📱 Compartilhamento WhatsApp

  • PDF + Comprovante de assinatura
  • Link para validação de QR Code
  • Enviado automaticamente após webhook (< 2s)
  • Paciente recebe em tempo real

FLUXO 3: Anamnese (Primeira Consulta)

📋 Seleção de Template

Paciente escolhe entre "Primeira Consulta" (abas completas) ou "Retorno" (formulário simplificado)

Navegação por Abas (5 Etapas)

1️⃣ Queixa Principal
2️⃣ Histórico
3️⃣ Hábitos & Risco
4️⃣ Exame Físico
5️⃣ Resumo & Assinar

ABA 1: Queixa Principal 🔴

  • Motivo da consulta (textarea)
  • Localização: 8 regiões (ombro, cotovelo, punho, coluna, quadril, joelho, tornozelo)
  • Duração dos sintomas
  • Intensidade: escala visual 0-10 com cores
  • O que piora? (textarea)
  • O que melhora? (textarea)

ABA 2: Histórico 📜

  • Traumas anteriores
  • Cirurgias anteriores
  • Fisioterapia anterior
  • Outros tratamentos
  • Medicações atuais (com alertas de interações)
  • Alergias a medicações

ABA 3: Hábitos & Risco ⚠️

  • Profissão
  • Atividades físicas/esportes
  • Nível de sedentarismo (slider 1-10)
  • Tabagismo (sim/não)
  • Consumo de álcool
  • Qualidade do sono (boa/regular/ruim)

ABA 4: Exame Físico 🔍

  • Amplitude de movimento
  • Testes específicos (Neer, Speed, Lachman, etc.)
  • Presença de inflamação
  • Deformidades/assimetrias
  • Palpação de pontos-dolorosos

ABA 5: Resumo & Assinar ✅

  • Preview colorido de todos os dados
  • Cards por seção com ícones
  • Barra de progresso de preenchimento
  • Botão "Salvar Anamnese"
  • Opção de assinatura digital (ClickSign)

💾 Auto-save (Salva Automático)

  • Salva a cada campo preenchido (< 0.5s)
  • Indicador visual de sincronização
  • Recuperação automática em caso de desconexão
  • Status sincronizado com backend

✓ Validação de Campos

  • Campos obrigatórios marcados com asterisco
  • Alertas de interações medicamentosas
  • Validação de consistência de dados
  • Avisos de risco (sedentarismo alto + dor, etc.)

Barra de Progresso

Preenchimento: 50% concluído

🔄 Fluxo de Retorno (Follow-up)

  • Anamnese simplificada (não abas completas)
  • Comparação de dor (antes/depois com cores)
  • Evolução desde última consulta
  • Adesão ao tratamento (Excelente/Boa/Regular/Fraca)
  • Resposta ao tratamento
  • Novos sintomas aparecidos
  • Limitações atuais
  • Resumo automático com indicadores

📊 Armazenamento Estruturado

  • Tabela: patient_anamnesis (paciente_id, tipo, data_criacao)
  • Dados em JSON estruturado por aba
  • Histórico completo mantido (sem sobrescript)
  • Linked com prescriptions para análise de efetividade
  • Busca e filtro por condição/especialidade
